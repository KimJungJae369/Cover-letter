1. <사용자 중심의 웹 환경을 구축하는 프론트엔드 개발자>

패션 세일즈 및 MD로 근무하며 고객에게 최적의 스타일을 제안하고 만족을 이끌어내는 일에 집중했습니다. 이 과정에서 저는 고객이 어떤 순간에 불편함을 느끼고, 어떤 요소에서 구매를 결정하는지를 가까이에서 관찰할 수 있었습니다. 이러한 경험을 통해 ‘사용자 경험(UX)’이란 단순한 결과가 아니라, 사용자가 서비스를 인지하고 탐색하며 행동하는 전 과정의 흐름이라는 것을 이해하게 되었습니다.

오프라인 매장이라는 한정된 공간을 넘어, 더 많은 사용자에게 일관되고 직관적인 경험을 제공하고자 웹 개발로 커리어를 전향했습니다. 그중에서도 프론트엔드 개발은 사용자가 직접 마주하는 화면을 설계하고, 경험의 흐름을 구현하는 역할이라는 점에서 저의 강점과 가장 맞닿아 있다고 판단하여 고객의 반응을 기반으로 더 나은 경험을 만들어왔던 저의 경험을, 이제는 웹 환경에서 구조적으로 구현하고 싶었습니다.

이를 위해 HTML, CSS의 기본기를 다지는 것을 시작으로 React, TypeScript 등 프론트엔드 핵심 기술을 학습하며 역량을 쌓았습니다. 특히 수입/지출 분석 및 메모 기능을 갖춘 ‘파스텔 가계부 앱’을 개발하며 실무 감각을 익히겠다는 생각으로 개발을 시작했습니다.

초기에는 컴포넌트 간 상태 관리와 함수 계산의 복잡성에 한계를 느꼈지만 이를 해결하기 위해 Context API와 TypeScript 인터페이스, 상태 관리 라이브러리를 선제적으로 도입하여 전역 상태 관리 구조를 재설계하고 데이터 흐름을 안정화했습니다. 이 과정에서 단순히 기능을 구현하는 것을 넘어, 사용자의 입력 데이터 처리 화면 반영까지의 흐름을 하나의 경험으로 바라보게 되었고, 사용자 입장에서 끊김 없는 인터페이스를 만드는 것이 중요하다는 점을 체감했습니다.

또한 사용자 경험 개선을 위해 동적인 날짜 포맷팅 로직(getFullYear, padStart 활용)을 적용하며 정보 가독성을 높였고, 입력과 출력의 흐름을 단순화하여 사용자가 자연스럽게 서비스를 이용할 수 있도록 설계했습니다. 이러한 경험을 통해 UX는 디자인뿐 아니라 데이터 처리 방식과 상태 관리 구조까지 포함된다는 점을 이해하게 되었습니다.

단순한 기능 구현을 넘어 코드의 논리적인 ‘이유’를 파악하며, 사용자 경험까지 고려하는 개발자로 성장하는 데 첫걸음을 내디뎠습니다.


2. <단계적 문제 해결력과 소통 능력, 그리고 완벽주의 성향의 보완>

저의 가장 큰 장점은 상황을 객관적으로 분석하는 ‘단계적 문제 해결력’과 상대방의 입장을 헤아리는 ‘소통 능력’입니다.

패션 매장 근무 당시, 환불 불가 규정으로 인해 강하게 항의하는 고객을 응대하며 이 강점을 발휘했습니다. 당황하여 피하기보다는 문제 해결을 위해 단계적으로 접근했습니다. 우선 고객에게 차를 제공하여 상황을 환기하고, 불만 사항을 끝까지 경청했습니다. 이후 규정에 대한 명확한 설명과 함께 현실적인 대체 방안을 제안했습니다. 그 결과 고객은 상황을 납득하셨고, 다음 날 재방문하여 추가 구매를 진행하시며 지속적인 관계를 형성하는 단골 고객이 되었습니다.

이러한 문제 해결 프로세스를 기술적인 오류에도 동일하게 적용했습니다. ‘파스텔 가계부 앱’을 개발하던 중, 지출 내역 계산과 화면 출력 과정에서 로직 오류가 발생한 적이 있습니다. 무작정 코드를 수정하기보다 데이터 흐름을 역추적하는 코드 검토를 우선적으로 진행했습니다. 수천 줄의 코드를 디버깅하며 연산 로직의 타입 지정 오류와 오타를 발견했고, 이를 수정하여 정상적인 계산 결과를 구현했습니다. 오류 상황에서 AI에 전적으로 의존하기보다 직접 원인을 분석하고 해결해 내는 집요함을 개발 업무의 강점으로 삼겠습니다.

반면, 세부적인 디테일과 코드의 완성도에 집중하다 보니 작업 초기 단계에서 시간이 지연되는 경향이 있습니다. 작은 오타나 디자인의 픽셀 단위까지 맞추려는 완벽주의 성향이 때로는 프로젝트 속도를 늦출 수 있다는 점을 인지하고 있습니다. 이를 보완하기 위해 프로젝트 시작 전 전체 아키텍처를 설계하고 핵심 기능을 우선 구현한 뒤, 이후 세부적인 UI와 예외 처리를 개선하는 ‘애자일(Agile)’ 방식의 작업 프로세스를 적용하여 업무 효율성을 높이고 있습니다.

3. <인공지능보다 강한 ‘기초의 힘’을 기반으로 성장하는 개발자>

저는 ‘가장 쉬운 길’보다 ‘가장 확실한 길’을 선택하는 개발자입니다. 인공지능이 코드를 빠르게 생성해주는 시대이지만, 이를 제대로 활용하기 위해서는 기초에 대한 깊은 이해가 필수라고 생각합니다. 따라서 HTML과 CSS와 같은 기본 기술부터 구조와 원리를 중심으로 학습하며 탄탄한 기반을 쌓았습니다. 작은 태그 하나와 스타일 속성 하나가 전체 화면에 영향을 미친다는 점을 이해하며, 코드의 동작 원리를 스스로 설명할 수 있는 수준까지 학습했습니다.

이러한 기초를 바탕으로 React와 TypeScript를 익히고, 이를 ‘나만의 포트폴리오 웹사이트’ 제작에 적용했습니다. 컴포넌트 단위로 UI를 설계하고, 상태 관리와 데이터 흐름을 직접 구성하며 구조적인 개발을 경험했습니다. 특히 반응형 레이아웃 구현과 다국어 기능 적용 과정에서 예상치 못한 UI 깨짐과 상태 동기화 문제가 발생했지만, 문제 상황을 단계적으로 분석하며 해결과 동시에 CSS 구조를 재정리하고 상태 관리 로직을 개선하여 다양한 화면 환경에서도 안정적으로 동작하는 웹사이트를 구현했습니다. 이 과정을 통해 단순한 구현을 넘어, 문제의 원인을 분석하고 해결하는 능력을 키울 수 있었습니다.

또한 패션 업계에서 쌓은 디자인 도구 활용 경험을 프론트엔드 개발에 적극적으로 접목하여 Photoshop, Illustrator, 피그마를 활용해 디자인 의도를 정확히 이해하고, 이를 웹 환경에서 효율적으로 구현하는 방법을 고민했습니다. 단순히 디자인을 재현하는 데 그치지 않고, 컴포넌트 재사용성과 유지보수성을 고려한 구조로 구현하며 개발 효율을 높였습니다. 사용자 관점에서 가독성과 편의성을 고려해 색상, 간격, 레이아웃을 세밀하게 조정하는 과정 또한 반복적으로 학습했습니다.

앞으로는 탄탄한 기본 지식을 바탕으로 인공지능과 협업하는 개발자로 성장하겠습니다. 기초를 기반으로 AI가 생성한 코드를 비판적으로 검토하고 개선하며, 사용자 경험과 유지보수성을 함께 고려하는 개발자로서 회사의 서비스 품질을 높이는 데 기여하겠습니다

4. <동료에게는 신뢰받는 파트너, 사용자에게는 편리한 경험을 만드는 개발자>

입사 후 저는 맡은 기능을 구현하는 데 그치지 않고, 서비스의 완성도를 높이는 데 기여하는 개발자가 되겠습니다.

첫째, 디자인과 개발을 연결하는 협업의 중심 역할을 수행하여 패션 현장에서 다양한 이해관계자 사이를 조율하며 쌓은 소통 경험을 바탕으로, 디자이너의 의도를 정확히 이해하고 이를 웹 환경에 구현하겠습니다. 특히 디자인 도구 활용 경험을 살려 시안 단계에서부터 구조와 구현 방식을 함께 고민하고, 개발 단계에서는 컴포넌트 단위로 재사용 가능한 구조를 설계하여 협업 효율과 유지보수성을 높이고 또한 코드 리뷰와 적극적인 커뮤니케이션을 통해 팀 전체의 생산성을 높이는 데 기여하겠습니다.

둘째, 사용자 경험을 구조적으로 이해하고 개선하는 개발자가 되겠습니다. 저는 UX를 ‘단순히 보기 좋은 화면’이 아니라, 사용자가 서비스를 이용하는 전체 흐름 즉, 정보 인지 행동 피드백 반복의 과정으로 이해하고 있습니다. 따라서 버튼 하나의 위치나 문구뿐만 아니라, 데이터 입력 방식, 상태 변화, 로딩 흐름까지 모두 사용자 경험의 일부라고 생각합니다.

‘파스텔 가계부 앱’과 ‘나만의 포트폴리오’를 개발하며 사용자 편의를 고려한 날짜 포맷팅, 입력 흐름 단순화, 반응형 UI 개선 등을 적용했던 경험을 바탕으로, 실제 사용 과정에서 발생하는 불편 요소를 지속적으로 점검하겠습니다. 특히 사용자의 행동 흐름을 기준으로 UI를 개선하고, 불필요한 클릭이나 인지 비용을 줄이는 방향으로 인터페이스를 설계하겠습니다.

또한 작은 오류도 놓치지 않는 품질 중심의 개발을 실천하여 오타 하나, 상태 하나가 사용자 경험에 영향을 미친다는 책임감을 바탕으로 테스트와 검증 과정을 습관화하고, 안정적인 서비스 제공에 기여하여 실제 프로젝트에서 사소한 오류를 끝까지 추적하며 해결했던 경험을 바탕으로, 완성도 높은 결과물을 만들어내겠습니다.

입사 후에는 협업을 통해 더 나은 결과를 만들고, 사용자에게는 직관적이고 일관된 경험을 제공하는 개발자로 성장하여 맡은 역할 이상의 가치를 만들어내며 회사의 서비스 품질 향상에 기여하겠습니다.
