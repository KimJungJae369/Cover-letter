Journey

오프라인 경험을 디지털 UX로 확장했습니다

패션 세일즈 및 MD로 일하며 고객이 어떤 순간에 망설이고, 어떤 요소에서 신뢰를 느끼는지 가까이에서 관찰했습니다. 그 과정에서 UX는 보기 좋은 결과물이 아니라, 사용자가 인지하고 탐색하고 행동하는 전 과정의 흐름이라는 점을 체감했습니다.

이 경험은 웹 개발로의 전환으로 이어졌습니다. HTML과 CSS의 기본기를 다진 뒤 React와 TypeScript까지 학습하며, 사용자가 실제로 마주하는 화면과 흐름을 구조적으로 설계하는 프론트엔드 개발 역량을 쌓아왔습니다.

Quick Profile

  • 키워드UX, 구조화, 협업
  • 전환 배경패션 세일즈 · MD → 웹 개발
  • 학습 스택HTML, CSS, React, TypeScript
  • 핵심 관심사끊김 없는 사용자 흐름

사용자 경험은 화면의 장식이 아니라, 행동이 자연스럽게 이어지는 구조라고 생각합니다.

Projects

기능 구현을 넘어 경험의 연결을 고민했습니다

Project 01

파스텔 가계부 앱

수입과 지출, 메모 기능을 하나의 흐름으로 연결한 프로젝트입니다. 초기에는 상태 관리와 계산 로직이 복잡해지며 한계를 느꼈지만, Context API와 TypeScript 인터페이스를 도입해 전역 상태 구조를 재설계했습니다.

날짜 포맷팅과 입력 흐름 단순화까지 함께 다듬으면서, 데이터 처리 방식 자체가 UX의 일부라는 점을 실무적으로 이해하게 되었습니다.

Context API TypeScript UX Flow

Project 02

포트폴리오 웹사이트

컴포넌트 단위 UI 설계와 반응형 레이아웃, 다국어 기능을 직접 구현하며 구조적인 개발 경험을 확장한 프로젝트입니다. 예상치 못한 UI 깨짐과 상태 동기화 문제를 분석하고 CSS 구조와 상태 관리 로직을 재정리해 다양한 화면에서 안정적으로 동작하도록 개선했습니다.

Responsive Component UI Localization

Strengths

문제를 단계적으로 풀고, 상대의 입장을 놓치지 않습니다

단계적 문제 해결력

가계부 앱 개발 중 계산 로직과 화면 출력이 어긋났을 때, 무작정 코드를 바꾸지 않고 데이터 흐름을 역추적하며 원인을 좁혀 갔습니다. 그 결과 타입 지정 오류와 오타를 찾아 수정했고, 정상 동작을 복구했습니다.

문제 원인을 단계적으로 좁혀 정확하게 해결합니다.

소통 능력

패션 매장에서 환불 규정으로 감정이 격해진 고객을 응대할 때도 먼저 상황을 진정시키고, 끝까지 경청한 뒤 현실적인 대안을 제시했습니다. 기술 협업에서도 같은 태도로 상대의 맥락을 이해하고 조율하는 데 강점이 있습니다.

상대의 맥락을 이해하고 끝까지 조율하며 소통합니다.

보완 중인 점

디테일에 몰입해 초기 속도가 늦어지는 경향이 있어, 현재는 핵심 기능을 먼저 완성하고 이후 UI와 예외 처리를 개선하는 방식으로 작업 순서를 관리하고 있습니다.

핵심 기능을 먼저 완성하고 디테일은 뒤에서 정교화합니다.

Agile Improvement

Philosophy

가장 쉬운 길보다, 가장 확실한 길을 선택합니다

빠른 생성 도구가 많아진 시대에도, 저는 기본기를 중심에 둡니다. HTML과 CSS의 구조와 원리를 먼저 이해해야 더 큰 프레임워크와 도구를 제대로 다룰 수 있다고 믿기 때문입니다.

그래서 태그 하나, 스타일 속성 하나가 전체 화면과 경험에 어떤 영향을 주는지 설명할 수 있을 만큼 기초를 다졌고, 그 위에서 React와 TypeScript를 익히며 더 구조적인 개발 방식으로 확장해 왔습니다.

"사용자 경험은 화면의 모양이 아니라, 흐름의 설계에서 시작됩니다."

Vision

협업과 품질, 두 축으로 서비스 완성도를 높이겠습니다

01

디자인과 개발을 연결하는 협업

디자인 도구 경험과 현장 커뮤니케이션 역량을 바탕으로, 디자이너의 의도를 구조적으로 해석하고 재사용 가능한 컴포넌트로 구현하겠습니다.

02

사용 흐름을 기준으로 한 UI 개선

정보 인지, 행동, 피드백의 흐름을 기준으로 불필요한 클릭과 인지 비용을 줄이고, 더 자연스러운 인터페이스를 설계하겠습니다.

03

작은 오류도 놓치지 않는 품질 중심 개발

오타 하나와 상태 하나도 사용자 경험에 직접 연결된다는 책임감을 갖고, 테스트와 검증을 습관화해 안정적인 서비스를 만드는 데 기여하겠습니다.
